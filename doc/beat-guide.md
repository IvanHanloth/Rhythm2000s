# 律动组件（Beat Guide）：节拍提示

> 状态：草稿（2026-10-24）。由用户要求加入；尺寸、颜色、位置是第一版，试玩后再调。

一局里的节拍提示，形如 `((((O))))`：中间一个圆跟着节拍跳，两边的弧从外往中间靠，弧和圆重合的那一刻正好是拍点。玩家按 **H** 打开 / 关闭。界面上的名字是「Beat Guide」。

## 画面

| 部分 | 做法 |
| --- | --- |
| 中间的圆 | 一直按节拍跳：每拍拍点放到最大，随后在 1/4 拍内缩回。这一拍要按时同时闪成黄色 |
| 两边的弧 | 每一拍一对弧（左边 `(`、右边 `)`），提前 4 拍从两端出现，匀速往中间靠；到拍点时两边的弧合成一圈正好套住中间的圆，随后很快淡掉 |
| 弧的颜色 | 平常是灰色；这一拍玩家要按（跟打段的判定目标）时是黄色。要按的点在反拍上时，也单独画一对黄色的弧 |
| 按住（音量动作） | `volume-mute`、`menu-volume` 按下后要一直按到游戏自动松开，和普通节拍区分开：按下的弧和结束的弧之间连一条半透明黄色粗长条（高 28），结束的弧画得细一些；按住期间中间的圆保持黄色、外面一直套着黄圈，直到结束拍（2026-10-24 用户要求） |
| 底板 | 没有底板，弧和圆直接画在桌面上（2026-10-24 用户要求去掉） |
| 大小 | 中间的圆半径 18、拍点那一圈半径 32、每差一拍隔 56（画布 1280×720 的逻辑坐标），整条约 520 宽 |
| 位置 | 画面水平正中，垂直方向在中线偏下（中心 y = 520）；画在桌面界面之上、判定字样和轮次横幅之下（2026-10-24 用户要求） |

- 「要按」只算玩家要按的下：长按的松开算，游戏自己完成的（`volume-mute`、`menu-volume` 的第二下）不算，那一下画成按住的结束。
- 位置都由音频时间算出，不累加帧间隔（[AGENTS.md](../AGENTS.md) 工作约定 4）。

## 开关

- 系统演示（[level-design.md](level-design.md#规则-1开头由系统演示全部操作)）期间不管开关一直显示，帮玩家先认识它；演示结束、正文开始后按玩家的开关显示（2026-10-24 用户要求）。
- 关卡里按 **H** 切换，随时生效；默认关闭。开关状态保存在浏览器本地，下次打开游戏还是上次的状态（读写失败时按关闭处理，和其他设置一样，见 [settings.md](settings.md)）。
- 左下角的返回提示里写着当前状态，例如「Esc: back to the café · H: Beat Guide off」。

## 记成绩

- 正文（不含系统演示）里只要有任何时刻开着律动组件，这一局就算「用了辅助」。
- 结算窗口的得分框左上角显示「Beat Guide」标签（[results.md](results.md)）。
- 这一局创了新纪录时，最好成绩一起记下「用了辅助」；开场页的最好成绩写成「Best score 04250 (Beat Guide)」。之后不用辅助打出更高分时，标记去掉。
- 用了辅助的成绩照样可以刷新最好成绩（第一版规则，以后可能分开记）。
