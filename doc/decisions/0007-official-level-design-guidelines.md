# 0007 Official level design guidelines

- Status: Accepted; when the demos run is superseded by [ADR 0008](0008-demos-before-each-new-action.md)
- Date: 2026-10-24

## Context

The first charts were each written to show off one or two actions and ran 28–43 seconds; a player meeting an action for the first time had to guess at it mid-chart. The user asked for official guidelines: demonstrate every action first, go from easy to hard, and set a minimum length.

## Options

How to demonstrate:

1. **In the chart**: authors write teaching phrases at the start. Repeated in every chart, easy to miss an action, and impossible to skip or exclude from scoring uniformly.
2. **Generated by the system**: the game reads the chart's actions and demonstrates each, asking the player to play it back. Charts hold only real content.

Length: the user first proposed at least 3 minutes, then settled on at least 1 minute.

## Decision

- Option 2: the system runs a call-and-response round per action; each must be played back successfully before the next, a failure repeats it, and the chart starts once all pass (since [ADR 0008](0008-demos-before-each-new-action.md), each action is demonstrated right before the phrase that introduces it). The demo is practice and unscored; a "Skip tutorial" setting turns it off.
- Charts rise from easy to hard.
- The chart lasts at least 60 seconds (count-in and outro included, demo excluded).

Details in [level-design.md](../level-design.md), the setting in [settings.md](../settings.md).

## Consequences

- Existing charts must be lengthened past 1 minute and reordered easy to hard (deferred to the polish phase).
- Scenes support an unscored, repeatable demo stage; results and best scores count only the chart.
- A settings page is needed for "Skip tutorial", taking over the latency calibration from the dev panel (built in [ADR 0009](0009-settings-in-system-menus.md)).
- The chart format is unchanged: the demo is derived from the chart's actions.
