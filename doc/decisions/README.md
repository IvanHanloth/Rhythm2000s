# 决策记录（ADR）

重要决定（技术选型、架构、关键玩法规则）各记一条，保留「为什么这么选」，避免日后重复讨论。

## 命名

`NNNN-short-english-title.md`（英文小写、连字符分隔），编号递增，例如 `0001-tech-stack.md`。

## 模板

```markdown
# NNNN 标题

- 状态：提议 / 已采纳 / 已废弃（被 NNNN 取代）
- 日期：YYYY-MM-DD

## 背景
要解决什么问题，有哪些约束。

## 候选方案
列出考虑过的选项及各自的优缺点。

## 决定
选了什么。

## 影响
这个决定带来的后果、代价，以及后续需要做的事。
```
