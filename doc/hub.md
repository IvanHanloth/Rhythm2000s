# 开始界面与街区大厅

> 状态：草稿

开始界面和关卡选择都在同一个 3D 街区里完成。技术选型见 [ADR 0005](decisions/0005-街区大厅用Three.js.md)。

## 已确定（2026-10-24 用户确认）

- 开始界面用街景当背景，叠标题和菜单；点「开始游戏」后镜头落到角色身后，直接可以走动。
- 第三人称跟随 + 鼠标转视角。
- 一条 2000 年代风格的街道，有几家可以走进去的店；网吧里的电脑是关卡入口，走到电脑前坐下开始这一关。
- 场景里（招牌、海报、屏幕、店名）的文字一律用英文；叠在画面上的菜单、提示、对话框仍用中文。
- 场景是写实风格；有年代特征的道具由用户用 Tripo / Blender 制作，规格和清单见 [hub-assets.md](hub-assets.md)。
- 场景里要有千禧年元素（2026-10-24 用户要求）。
- 玩家角色是 DeepSeek 鲸鱼娘，用现成的 3D 模型（ai-girls-3d 成年版，CC BY 4.0，来源与修改见 assets/README.md）。模型没有动画，走路、坐下、打字由代码转动骨骼。

## 流程

```
开始界面 ──「开始游戏」──► 街上自由走动 ──进门──► 网吧
   ▲                                              │ 走到电脑前按 E
   │                                              ▼
   └──── 暂停菜单「回到标题」              坐下：屏幕上显示关卡信息
                                                  │ E 开始 / Esc 起身
                                                  ▼
                                      镜头推进屏幕 ──► 电脑里的关卡列表 ──► 节奏关卡
                                                  │ 关卡列表上按 Esc / 点「后退」
                                                  ▼
                                            回到这个座位
```

电脑里的关卡列表（XP 资源管理器 / Mac Finder）见 [level-select.md](level-select.md)。关卡里按 Esc 先回到关卡列表，再按一次才回到座位。

## 操作

| 按键 | 作用 |
| --- | --- |
| W A S D | 移动（相对镜头方向） |
| Shift | 跑 |
| 鼠标 | 转镜头（点击画面后锁定鼠标） |
| E | 进门、坐下、开始、和店员说话 |
| Esc | 放开鼠标并暂停；坐着时起身；电脑里的关卡列表上回到网吧；关卡里回到关卡列表 |

## 暂定内容（第一版占位，都可以改）

以下店名、布局、文案都是第一版占位，用户尚未确认：

- **街道**：黄昏，东西走向的一条双车道马路，两侧人行道。北侧三家可以进的店，南侧是不能进的楼面、报刊亭、电话亭、公交站。路灯、电线杆、行道树、广告牌做点缀。
- **TURBO NET CAFE**（网吧，中间）：两排共 8 台电脑，前台没人，只留了价目表和便签。
  - 一台 Windows XP 机器 → 「Windows XP 桌面」场景。
  - 一台半透明外壳的一体机 → 「Mac 桌面」场景（场景本身还是占位）。
  - 其他机器有人在用，或贴着「维修中」。
- **MILLENNIUM MUSIC**（音像店，西侧）：货架、柜台。现在只能看柜台上的纸条。
- **SUPER ARCADE**（电玩城，东侧）：几台街机。现在机器都在「维修中」。
- 音像店、电玩厅以后能不能成为新场景的入口，待定。
- **千禧年元素**：
  - 街上：横跨马路的两条横幅（WELCOME TO THE NEW MILLENNIUM · 2000、Y2K READY）、南侧楼顶的 LED 滚动屏（HAPPY NEW MILLENNIUM）、两块楼顶广告牌（512K 宽带、PC 2000 整机）、电器行门口的 CRT 电视墙、IC 卡电话亭、报刊亭门口卖的随身听。
  - 南侧店铺：VCD 出租、寻呼机 / 手机、一小时冲印、电脑城、彩票站；卷帘门上贴着装机、彩屏手机、和弦铃声、Flash 游戏、数码相机的小广告。
  - 店里：网吧的「OPEN 24H」霓虹灯牌和 Y2K READY / ADSL 海报，音像店柜台上的手提录音机和磁带机，电玩城门头的「INSERT COIN」滚动屏和电视 + 游戏机试玩台，网吧前台的米色老笔记本。
- 网吧里暂时没有路人：之前代码拼的人偶不够好看，去掉了，等有合适的模型再加。
