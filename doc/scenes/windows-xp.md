# 场景：Windows XP 桌面

> 状态：草稿

## 视觉基调

蓝天绿草风格的壁纸、蓝色任务栏、绿色「开始」按钮、圆角蓝色标题栏窗口。（界面尽量贴近原版，可以直接使用 `assets/reference/windows-xp/` 的原版素材，见 [ADR 0004](../decisions/0004-界面贴近原版.md)。）

## 已确定的动作

- 弹出窗口
- 关闭窗口
- 收邮件
- 点击刷新

## 候选 / 待讨论

> 以下只是想法，尚未确定。

- 托盘气泡提示「发现新硬件」，跟着节奏点掉
- 一组错误对话框层层叠出（经典的「错误窗口拖影」画面），按节奏逐个关闭
- 弹窗广告越弹越多，节奏加快
- 拖动文件到回收站
- 开机音效 / 关机音效作为乐句的开头与结尾
