# 场景：2000 年前后的 Mac 桌面

> 状态：草稿

## 视觉基调

需要先确定参照哪个版本：

- **Mac OS 9**（1999 年）：灰色铂金风格界面、条纹标题栏、笑脸 Finder 图标
- **Mac OS X 早期 Aqua**（2000 年发布预览版，2001 年正式发布 10.0）：糖果质感按钮、红黄绿三色窗口按钮、Dock 栏的放大与弹跳动画

（全部原创绘制，不使用苹果原版素材。）

## 已确定的动作

- 弹出窗口
- 关闭窗口
- 收邮件
- 点击刷新
