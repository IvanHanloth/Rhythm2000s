# 场景：2000 年前后的 Mac 桌面

> 状态：草稿

## 视觉基调

参照对象是**简体中文版 Mac OS X 10.0–10.2 的早期 Aqua**（Cheetah / Puma / Jaguar，2026-10-24 用户确认）：标题栏和窗口背景带明显的细条纹（pinstripe），红黄绿三颗果冻按钮，蓝色果冻默认按钮，半透明 Dock。界面文字用中文版的说法（「文件」「编辑」「显示」「前往」「窗口」「帮助」「好」）。界面尽量贴近原版，可以直接使用 `assets/reference/mac-os-x/` 的原版素材，见 [ADR 0004](../decisions/0004-界面贴近原版.md)。

10.3 以后的金属拉丝 Finder、10.5 的立体 Dock 都不在参照范围内。Mac OS 9 铂金风格暂不做。

## 界面部件（2026-10-24 重新设计）

### 尺寸

- 部件按原版的像素尺寸绘制（菜单栏、标题栏 22 像素高，按钮 20 像素高，滚动条 15 像素宽），整块桌面放大 1.25 倍铺满 1280×720 的画布，相当于一台 **1024×576** 分辨率的 Mac，与 XP 场景的做法一致。
- Follow me / Your turn 横幅和判定字样不属于 Mac 界面，仍按画布坐标绘制。

## 玩法（2026-10-24）

用户选定 Mac 场景先做四类动作，玩法与 XP 的 MVP 相同（[prototypes/mvp.md](../prototypes/mvp.md)）：示范小节里电脑按节奏「出事」，跟打小节里玩家在同样的拍点上按空格键或点击画面，一下处理一个。第几下就处理第几个出现的目标（[chart-format.md](../chart-format.md#场景附加规则)）。判定窗口、伴奏鼓点都沿用 XP 的暂定值。

动作 ID 按 Mac 原版的类名 / 常量取名（[ADR 0006](../decisions/0006-动作按界面部件类名命名.md)）：

| 动作 ID | 原版对应 | 示范段（在拍点上） | 跟打段（玩家在拍点上按） | Miss |
| --- | --- | --- | --- | --- |
| `alert-note` | Carbon `kAlertNoteAlert`（`NSInformationalAlertStyle`） | 弹出一个提示框，图标是发出提示的程序 | 按下「好」，提示框关闭 | 提示框左右抖一下，留到这一乐句结束再淡出 |
| `alert-caution` | `kAlertCautionAlert`（`NSWarningAlertStyle`） | 弹出提示框，图标是黄色警告三角，右下角带程序小图标 | 同上 | 同上 |
| `alert-stop` | `kAlertStopAlert`（`NSCriticalAlertStyle`） | 弹出提示框。Mac OS X 的停止提示框用程序图标（不再是 OS 9 的红色停止牌），所以只能靠文字和提示音区分 | 同上 | 同上 |
| `dock-bounce` | `NSApplication requestUserAttention:`（`NSCriticalRequest`，一直弹到用户理会为止） | Dock 上一个程序图标高高跳起，在拍点上落下，之后一直小幅弹跳 | 点一下，图标停下，下面出现「正在运行」的小三角 | 继续弹到这一乐句结束 |
| `mail-new` | Mail 收到新邮件 | Dock 上的 Mail 图标轻跳一下（`NSInformationalRequest`，只跳一次），红色未读角标加 1 | 读一封，角标减 1，减到 0 时消失 | 角标留到这一乐句结束 |
| `window-miniaturize` | `NSWindow miniaturize:` | 弹出一个文稿窗口 | 按下黄色最小化按钮，窗口缩进 Dock | 窗口左右抖一下，留到这一乐句结束再淡出 |

- 最小化用的是原版「缩放效果」（系统预置里可以在「神灯效果」和「缩放效果」之间选）。神灯效果需要网格变形，先不做。
- 提示框和文稿窗口共用画面上的 6 个位置；同一乐句里最多 6 个，超过会叠在一起。Dock 弹跳的图标按乐句内的顺序依次取 iChat、Safari、iTunes、iPhoto、iCal、QuickTime Player、Sherlock、系统预置。
- 下一个该处理的提示框 / 窗口显示为活动状态（默认按钮是蓝色、标题栏有红黄绿按钮），其余显示为非活动，提示玩家下一个目标是谁。

### 选谱面

进场景先看到 Finder 的关卡列表（图标视图 + 「简介」窗口），用鼠标点选，流程和操作见 [level-select.md](../level-select.md)（2026-10-24 取代原来临时的列表视图选谱面窗口）。

| 部件 | 原版对应 | 内容 |
| --- | --- | --- |
| Finder 窗口 | Jaguar Finder 图标视图 | 标题「我的关卡」；工具栏（后退、显示方式、电脑、个人、搜索框）；状态栏「N 项」；白色内容区按 5 列排关卡图标（64 像素），选中时图标衬灰色圆角底、名字是蓝色胶囊白字 |
| 简介窗口 | 「显示简介」（⌘I） | 选中关卡的大图标、名字，「▾ 一般信息：」里列动作、速度、乐句、时长；右下「返回」「开始」，「开始」是默认按钮 |

### 音效

全部取自 `assets/reference/mac-os-x/sounds/` 的原版提示音（加载时自己解码 AIFF，Chrome 的 `decodeAudioData` 不支持 AIFF）。**原版的提示框不分种类，统一响用户选的「提示音」**；这里为了让玩家听出区别，每种动作配了一个，都是暂定：

| 时机 | 文件 |
| --- | --- |
| `alert-note` 弹出 | `Glass.aiff` |
| `alert-caution` 弹出 | `Funk.aiff` |
| `alert-stop` 弹出 | `Basso.aiff` |
| `dock-bounce` 落下 | `Pop.aiff` |
| `mail-new` 到达（Mail 原版的「新邮件」声音本地没有） | `Ping.aiff` |
| `window-miniaturize` 弹出窗口（原版没有声音） | `Bottle.aiff` |
| 玩家处理掉一个目标（Perfect / Good） | `Tink.aiff` |
| Miss | `Sosumi.aiff` |
| 一局结束，弹出结果 | `Hero.aiff` |
