# Scene: a Mac desktop from around 2000

> Status: Draft

## Look

The reference is **the early Aqua of US English Mac OS X 10.0–10.2** (Cheetah / Puma / Jaguar): pinstriped title bars and window backgrounds, red / yellow / green gel buttons, a blue gel default button and a translucent Dock. Interface text follows the English version ("File", "Edit", "View", "Go", "Window", "Help", "OK"). As close to the original as possible, using the assets in `assets/reference/mac-os-x/` ([ADR 0004](../decisions/0004-authentic-os-look.md)). Brushed-metal Finder (10.3+), the 3D Dock (10.5) and Mac OS 9 Platinum are out of scope.

## Widgets

Widgets are drawn at original pixel size (22 px menu bar and title bars, 20 px buttons, 15 px scrollers) and the desktop is scaled 1.25× to fill the canvas, like a Mac at **1024×576**, as in the XP scene. The turn banner and judgement labels use canvas coordinates. Code in `src/scenes/mac-2000/components/`, colours in `src/theme/aqua.ts`.

## Gameplay

Played like the XP MVP ([prototypes/mvp.md](../prototypes/mvp.md)): in the call bar the computer makes things happen on the beat; in the response bar the player presses Space or clicks on the same beats, one press per target, the n-th press handling the n-th target ([chart-format.md](../chart-format.md#scene-rules)). Judgement windows and drums are the XP provisional values. Action IDs follow Mac class names and constants ([ADR 0006](../decisions/0006-actions-named-after-ui-classes.md)).

| Action ID | Original | Call (on the beat) | Response (the player on the beat) | Miss |
| --- | --- | --- | --- | --- |
| `alert-note` | Carbon `kAlertNoteAlert` (`NSInformationalAlertStyle`) | An alert pops up with the issuing app's icon | Click OK; it closes | Shakes, stays until the phrase ends, fades |
| `alert-caution` | `kAlertCautionAlert` (`NSWarningAlertStyle`) | An alert with the yellow caution triangle and an app badge | Same | Same |
| `alert-stop` | `kAlertStopAlert` (`NSCriticalAlertStyle`) | An alert; OS X stop alerts use the app icon (no OS 9 stop sign), so only text and sound tell it apart | Same | Same |
| `dock-bounce` | `requestUserAttention:` (`NSCriticalRequest`, bounces until answered) | A Dock icon jumps high, lands on the beat, then keeps hopping | Click it; it stops and gets the running triangle | Keeps bouncing to the phrase end |
| `mail-new` | New mail in Mail | Mail hops once (`NSInformationalRequest`) and its badge goes up by one | Read one; the badge goes down, disappearing at 0 | The badge stays to the phrase end |
| `window-miniaturize` | `NSWindow miniaturize:` | A document window opens | Click the yellow button; it shrinks into the Dock | Shakes, stays until the phrase ends, fades |
| `menu-apple` | Apple menu (`NSMenu`) | The virtual mouse clicks the Apple and the menu drops; **half a beat later** it clicks an item, which blinks, and the menu closes | Two presses: the Apple on the beat, an item half a beat later | First missed: no menu; second missed: the menu stays to the phrase end |
| `dock-trash` | Dock Trash (`NSWorkspaceRecycleOperation`) | A file drops above the Dock and lands with a bounce on the beat | It arcs into the Trash, shrinking, and the Trash turns full | Shakes, stays until the phrase end, fades |
| `sheet-save` | Save sheet (`NSWindow beginSheet:`) | An unsaved document opens a beat early; the virtual mouse clicks close on the beat and the sheet slides out; **half a beat later** "Don't Save", and the window closes | Another window opens in the same place; two presses: close on the beat, Don't Save half a beat later | First missed: no sheet, the window shakes; second missed: the sheet stays; both fade at the phrase end |
| `ichat-message` | New iChat message | A message window grows out of the iChat Dock icon on the beat | Click it; it shrinks back into iChat | Shakes, stays until the phrase end, fades |
| `menu-volume` | Menu bar volume (`NSMenuExtra`) | 1/4 beat early the speaker mutes and the menu drops with the slider at the bottom; the virtual mouse grabs it on the beat, drags it to the top over **1 beat** and releases; the menu closes and the speaker unmutes | Press on the beat; the slider rises over 1 beat and releases by itself. **Only the press is judged**, as XP's `volume-mute` ([windows-xp-levels.md](windows-xp-levels.md)) | The slider stays at the bottom; the menu shakes and closes |

Provisional details:

- Minimising uses the original Scale Effect; the Genie Effect needs mesh warping and isn't done.
- Alerts, document windows and `sheet-save` windows share 6 screen slots (at most 6 per phrase). Bouncing icons take, in phrase order, iChat, Safari, iTunes, iPhoto, iCal, QuickTime Player, Sherlock, System Preferences.
- The next alert or window to handle is active (blue default button, coloured window buttons), the rest inactive, so the player can see what's next.
- `dock-trash` files line up above the Dock (up to 6), left to right, clear of the window slots; the Trash empties at each phrase start.
- `menu-apple` hangs at the top left, one at a time; the picked item rotates through About This Mac, System Preferences…, Force Quit…, Get Mac OS X Software… (nothing opens).
- `ichat-message` windows stack up from the iChat icon, at most 3 per phrase; lines rotate ("Sam: u there?", "Alex: did you get my email?", "Jo: brb").
- `menu-volume` is one at a time and visual only; letting go of Space or the mouse doesn't affect it.
- Judgement labels: right of the menu for `menu-apple`, left of the menu for `menu-volume`, above the target otherwise.

Alert and document texts are original, imitating the period tone ("The application iTunes has unexpectedly quit.").

### Virtual mouse

As in the XP scene ([windows-xp.md](windows-xp.md#virtual-mouse)), sharing the path code: in the call it demonstrates, stopping on each new target on its beat (and clicking twice for two-press actions); in the response it waits on the next target and clicks in place when the player presses, leaving once the press is judged. The player's own pointer is hidden during a round.

| Target | Where it clicks |
| --- | --- |
| Alert | Centre of the default OK button |
| Document window | The yellow minimise button |
| `dock-bounce` / `mail-new` | The icon in the Dock |
| `menu-apple` | The Apple, then the item |
| `dock-trash` | The file icon |
| `sheet-save` | The red close button, then "Don't Save" |
| `ichat-message` | The bubble |
| `menu-volume` | The bottom of the slider, dragging to the top over 1 beat |

All from the original alert sounds in `assets/reference/mac-os-x/sounds/` (AIFF decoded by our own code, since Chrome's `decodeAudioData` can't). **Original alerts all share the user's chosen alert sound**; each action gets its own here so they can be told apart (all provisional):
