## 写作约定

- 使用中文 Markdown，每篇文档开头注明**状态**：`草稿` / `评审中` / `已定稿`。
- 已确定的内容与想法、提案要分开写。提案统一放在「候选 / 待讨论」小节，不要写成已定事项。
- 谱面和节奏相关的时间一律以「拍」为单位，例如「第 3 拍的反拍」，不要写毫秒。
- 新增文档后，在本索引中登记。
