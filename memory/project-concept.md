rhythm2000s 是一款玩法完全仿照《节奏天国》的节奏游戏（先示范带节拍的动作，玩家按同样节奏重复），题材是 21 世纪初的电脑元素。首批场景已确定为 Windows XP 桌面和 2000 年前后的 Mac 桌面，动作示例有弹出/关闭窗口、收邮件、点击刷新。

2026-10-24 完成仓库初始化（AGENTS.md、doc/、memory/）。此时技术栈、输入方式、美术与音乐方向均未确定。

**Why:** 项目还在设计早期，很多看似合理的细节其实都没定。
**How to apply:** 不要把提案当成已定事项；需要选型或补全设计时，先向用户确认，并把结果记录到 doc/decisions/。
